# un_named_project

The public face of a Kenya-first trust protocol — an open contract layer and an
open Rust engine that let any approved app run protected trades, chama-style
capital, and community groups on-chain, without the chain ever knowing what a
"mango" is.

This repository holds **only** the white paper and the architecture site. The
protocol code lives elsewhere and is published when the audit gate is passed.

- **White paper** — [`WHITEPAPER.md`](WHITEPAPER.md)
- **Architecture site** (animated, works offline) — `docs/`
  - [Overview](docs/index.html)
  - [Contract layer](docs/contracts.html) — six playable flows over the 15 contracts
  - [Engine layer](docs/engine.html) — how a phone-signed intent becomes a transaction, and how truth is rebuilt from events

If GitHub Pages is enabled for this repo, the site is served from `/docs`.
